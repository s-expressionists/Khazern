# AI Usage Policy

We welcome contributions made with the help of AI coding assistants
(such as Claude Code, Cursor, GitHub Copilot, or ChatGPT). However, to
maintain code quality and respect maintainer review bandwidth, all
contributors must follow these rules:

## 1. Mandatory Disclosure
* You must explicitly state in your Pull Request description if AI
  tools were used.
* Name the specific tool(s) used (e.g., Cursor, Claude, Copilot).
* Briefly describe the extent of AI involvement (e.g., "Used for
  drafting unit tests" or "Used for refactoring the parser function").
* Commit messages must also explicitly specify AI usage.

## 2. Human-in-the-Loop & Accountability
* **You own what you submit.** You must fully understand, review, and
    test any AI-generated code before submission.
* Do not submit bulk-dumped or unverified AI output. 
* Do not rely solely on "it compiles" or "tests pass"—verify the
  change works end-to-end in an environment you can manually access.

## 3. Prohibited Uses
* Undisclosed AI usage in any part of a contribution.
* Code written for platforms or environments you cannot personally
  test on.
* AI-generated media, code comments, or issue/pull request text.
